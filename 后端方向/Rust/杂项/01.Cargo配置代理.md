## 写入如下配置即可

- Linux/macOS：`~/.cargo/config.toml`
- Windows：`C:\Users\用户名\.cargo\config.toml`

```toml
# 字节跳动
[source.crates-io]
replace-with = 'rsproxy-sparse'

[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"
```

```toml
[source.crates-io]
replace-with = 'ustc'

[source.ustc]
registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
```

## 正向代理

文件：`vi $HOME/.cargo/config.toml`

```toml
[http]
proxy="127.0.0.1:10086"
```

## 配置本地镜像代理

```toml
# ~/.cargo/config.toml

[registries.cargo-proxy]
index = "sparse+http://192.168.6.21:8081/repository/July-Cargo-Mirror/"

[source.crates-io]
replace-with = "cargo-proxy"
```
