# STM32 芯片命名规则

## 1. 命名规则概述

STM32 是意法半导体（STMicroelectronics）推出的基于 Arm Cortex-M 内核的 32 位微控制器产品系列。

STM32 芯片采用字母与数字组合的方式进行型号命名。通过型号通常可以识别芯片所属系列、产品子系列、引脚数量、Flash 容量、封装形式以及工作温度范围等信息。

以 `STM32F051R8T6` 为例，其基本命名结构如下：

```text
STM32  F  051  R  8  T  6
  │    │   │   │  │  │  │
  │    │   │   │  │  │  └── 温度等级
  │    │   │   │  │  └───── 封装类型
  │    │   │   │  └──────── Flash 容量
  │    │   │   └─────────── 引脚数量
  │    │   └─────────────── 产品子系列
  │    └─────────────────── 产品类型
  └──────────────────────── 产品品牌
```

需要注意，以上是该型号所采用的编码结构，不同 STM32 系列可能存在不同的编码方式。

## 2. 各字段含义

### 2.1 产品品牌：STM32

`STM32` 表示 STMicroelectronics 推出的 32 位微控制器产品品牌。

其主要产品特点：

- 基于 Arm Cortex-M 系列处理器内核。
- 集成 Flash、SRAM 等存储资源。
- 集成 GPIO、USART、SPI、I2C、ADC、定时器等外设。
- 广泛应用于工业控制、消费电子、汽车电子、物联网等领域。

### 2.2 产品类型：F

紧跟 STM32 后面的字母表示产品类型或产品线。

常见系列标识：

| 标识 | 产品系列    | 主要特点                     |
| ---- | ----------- | ---------------------------- |
| F    | STM32F 系列 | 通用型 MCU，覆盖多种性能等级 |
| L    | STM32L 系列 | 超低功耗 MCU                 |
| H    | STM32H 系列 | 高性能 MCU                   |
| G    | STM32G 系列 | 主流通用型 MCU               |
| U    | STM32U 系列 | 超低功耗 MCU                 |
| W    | STM32W 系列 | 无线连接 MCU                 |
| C    | STM32C 系列 | 经济型 MCU                   |

注意：以上是常见产品线标识，并非完整列表。不同代际的产品定位可能有所调整。

### 2.3 产品子系列：051

紧跟产品类型后面的数字通常用于区分具体产品系列或子系列。

例如：

| 型号      | 产品系列 |
| --------- | -------- |
| STM32F030 | F0 系列  |
| STM32F051 | F0 系列  |
| STM32F103 | F1 系列  |
| STM32F407 | F4 系列  |
| STM32F767 | F7 系列  |
| STM32H743 | H7 系列  |

需要注意，数字编码并不直接代表 CPU 主频、内核位数或性能等级。具体芯片的内核类型、主频及外设能力需要查阅数据手册。

### 2.4 引脚数量：R

产品子系列后面的字母通常用于表示芯片的引脚数量。

以 STM32F051 系列为例：

| 编码 | 引脚数量 |
| ---- | -------: |
| K    |       32 |
| T    |       36 |
| C    |       48 |
| R    |       64 |

例如：

- STM32F051K8：32 引脚。
- STM32F051C8：48 引脚。
- STM32F051R8：64 引脚。

注意：不同系列的引脚编码与数量可能不同，不能直接将上述对照表套用到全部 STM32 芯片。

### 2.5 Flash 容量：8

引脚数量后面的数字通常表示用户程序 Flash 存储容量。

以 STM32F051 系列为例：

| 编码 | Flash 容量 |
| ---- | ---------: |
| 4    |      16 KB |
| 6    |      32 KB |
| 8    |      64 KB |

例如：

- STM32F051R4：16 KB Flash。
- STM32F051R6：32 KB Flash。
- STM32F051R8：64 KB Flash。

需要注意：

1. 这里表示的是片上用户程序 Flash 容量，不是 SRAM 容量。
2. 不同产品系列的容量编码并不完全相同。
3. 某些新系列使用字母表示更大的 Flash 容量，例如 B、C、E、G 等。

### 2.6 封装类型：T

Flash 容量后面的字母表示芯片的封装形式。

以 STM32F051 系列为例：

| 编码 | 封装类型 |
| ---- | -------- |
| H    | UFBGA    |
| T    | LQFP     |
| U    | UFQFPN   |
| Y    | WLCSP    |

常见封装说明：

| 封装   | 特点                              |
| ------ | --------------------------------- |
| LQFP   | 四边引脚封装，便于 PCB 焊接和调试 |
| UFBGA  | 超细间距球栅阵列封装              |
| UFQFPN | 四边无引脚扁平封装                |
| WLCSP  | 晶圆级芯片尺寸封装                |

例如：

`STM32F051R8T6` 中的 `T` 表示 LQFP 封装。

结合前面的 `R`，可以知道该芯片采用 64 引脚 LQFP 封装。

### 2.7 温度等级：6

型号最后面的数字通常表示芯片的工作温度等级。

以 STM32F051 系列为例：

| 编码 | 工作温度范围 |
| ---- | ------------ |
| 6    | -40℃ ~ +85℃  |
| 7    | -40℃ ~ +105℃ |

例如：

- STM32F051R8T6：-40℃ ~ +85℃。
- STM32F051R8T7：-40℃ ~ +105℃。

温度等级会影响芯片在不同环境温度下的适用范围。

注意：不同 STM32 系列可能具有不同的温度等级定义，实际使用时应以对应型号的数据手册为准。

## 3. 完整订货型号的扩展后缀

除了基本型号之外，ST 还可能在型号后面增加额外字符，用于表示特殊选项、编程版本或包装方式。

例如：

```text
STM32F051R8T6TR
                 │
                 └── TR：Tape and Reel（编带包装）
```

常见情况：

| 后缀       | 含义                                                 |
| ---------- | ---------------------------------------------------- |
| 无额外后缀 | 通常为托盘包装（Tray），具体以订货信息为准           |
| TR         | Tape and Reel，编带包装                              |
| xxx        | 特定编程产品的代码标识，具体含义需要查阅对应产品资料 |

编带包装主要用于自动化贴片生产，托盘包装则常用于其他生产及装配场景。

此外，部分产品还可能具有专用软件、特殊编程内容或其他定制选项。这些后缀不能简单地跨系列通用解释。

## 4. 完整型号解析示例

以 `STM32F051R8T6` 为例：

| 字段       | 编码  | 含义             |
| ---------- | ----- | ---------------- |
| 产品品牌   | STM32 | ST 32 位微控制器 |
| 产品类型   | F     | 通用型产品线     |
| 产品子系列 | 051   | STM32F051 子系列 |
| 引脚数量   | R     | 64 引脚          |
| Flash 容量 | 8     | 64 KB            |
| 封装类型   | T     | LQFP             |
| 温度等级   | 6     | -40℃ ~ +85℃      |

因此，`STM32F051R8T6` 表示：

一颗属于 STM32F0 产品系列的通用型 32 位微控制器，具有 64 KB Flash，采用 64 引脚 LQFP 封装，工作温度范围为 -40℃ 至 +85℃。

其主要硬件参数：

| 参数     | 规格           |
| -------- | -------------- |
| CPU 内核 | Arm Cortex-M0  |
| 最高主频 | 48 MHz         |
| Flash    | 64 KB          |
| SRAM     | 8 KB           |
| GPIO     | 最多 55 个 I/O |
| 封装     | LQFP64         |
| 工作电压 | 2.0V ~ 3.6V    |
| 工作温度 | -40℃ ~ +85℃    |

## 5. 不同 STM32 系列的命名差异

STM32 产品线经过多代发展，不同系列在命名规则上存在一定差异。

例如：

| 系列    | 典型型号      | 内核       |
| ------- | ------------- | ---------- |
| STM32F0 | STM32F051R8T6 | Cortex-M0  |
| STM32F1 | STM32F103C8T6 | Cortex-M3  |
| STM32F4 | STM32F407VGT6 | Cortex-M4  |
| STM32F7 | STM32F767ZIT6 | Cortex-M7  |
| STM32H7 | STM32H743VIT6 | Cortex-M7  |
| STM32G0 | STM32G071RBT6 | Cortex-M0+ |
| STM32L4 | STM32L476RGT6 | Cortex-M4  |

虽然这些型号在结构上具有相似性，但具体编码所代表的容量、引脚数量、封装及温度等级，仍然需要结合对应系列的数据手册进行判断。

尤其需要注意：

- 不要认为所有系列的数字容量编码都一致。
- 不要认为相同封装字母在所有系列中都代表相同引脚数量。
- 不要仅凭型号判断 CPU 内核和主频。
- 不要仅凭系列名称判断芯片的全部外设能力。

## 6. 如何查询具体型号的命名信息

ST 官方提供了完整的数据手册和产品信息查询入口。

推荐查询方式：

1. 打开 ST 官方网站。
2. 搜索具体芯片型号，例如 `STM32F051R8T6`。
3. 进入对应产品页面。
4. 下载 Datasheet（数据手册）。
5. 查找 `Ordering information` 或 `Ordering information scheme` 章节。

该章节通常会提供型号中各个字符的准确解释。

官方查询入口：

- [STMicroelectronics 官方网站](https://www.st.com/)
- [STM32F051R8 产品页面](https://www.st.com/en/microcontrollers-microprocessors/stm32f051r8.html)
- [STM32F051 系列官方数据手册](https://www.st.com/resource/en/datasheet/stm32f051r6.pdf)

**总结：STM32 型号可以帮助我们快速识别芯片的产品系列、存储容量、封装及温度等级，但命名规则并非完全统一。选型和硬件设计时，最终应以具体型号的官方 Datasheet 为准。**
